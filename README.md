Swift Exit is a paper-trading scalper for pump.fun bonding curves: it buys a small fixed stake in young coins while fresh buying outweighs selling, then exits fast with a tight stop-loss, a trailing stop that rides spikes, a hard take-profit, and a time exit. Many small, short trades across many coins, never a concentrated bet.

## Run it

```sh
node main.ts
```
